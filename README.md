# Little Lemon - Réservation de table

Application web front-end développée avec React et Vite pour le projet final du certificat Meta Front-End Developer.

## Fonctionnalités
* Navigation dynamique avec React Router
* Formulaire de réservation complet avec validation côté client (HTML5 & React)
* Gestion des états via `useState` et `useReducer`
* Connexion à une API simulée pour les horaires disponibles
* Tests unitaires automatisés avec Vitest et React Testing Library
* Accessibilité optimisée (ARIA, sémantique)

## Instructions d'installation

1. Clonez ce dépôt sur votre machine locale :
   `git clone [VOTRE_URL_GITHUB]`
2. Naviguez dans le dossier du projet :
   `cd [NOM_DU_DOSSIER]`
3. Installez les dépendances :
   `npm install`
4. Lancez le serveur de développement :
   `npm run dev`
5. Pour lancer les tests unitaires :
   `npm test`
